# AdVoice Studio

סטודיו מתקדם ליצירת פרסומות קוליות (TTS) לקווי שמע והודעות התראה, מעוצב בדיוק לפי מפרט **Apple iOS 18 UI Kit** (Light Theme) עם טיפוגרפיית **SF Pro Text** ו-**פלוני אאא**.

## תכונות עיקריות

- **קופירייטינג רדיופוני חכם**: שכתוב הודעה גולמית לתשדיר רדיו קליט, משכנע ומניע לפעולה.
- **כלל בל יעבור להמרת מספרי טלפון**: כל מספר (סלולרי, קווי, כוכבית, 1-800) מומר אוטומטית למילים מדוברות בעברית (למשל `052-5021055` -> `״אפס חמש שתיים, חמש אפס שתיים, אחת אפס חמש חמש״`).
- **קריינות Google AI Studio TTS**: בחירה מתוך 30 קולות רשמיים ומודלי `gemini-2.5-flash-preview-tts` ו-`gemini-2.5-pro-preview-tts`.
- **ייצוא והשמעה ב-MP3 (128kbps)**: המרה פנימית ישירה מקובץ ה-PCM של גוגל ל-MP3 קל ואיכותי.
- **שיתוף ישיר**: שיתוף קובץ האודיו ישירות ל-WhatsApp ו-Telegram במובייל, והורדה מהירה עם גישה ישירה בדסקטופ.
- **שמירת היסטוריה מקומית (IndexedDB)**: כל הפרסומות נשמרות באופן קבוע ומאובטח במכשיר המשתמש.
- **אבטחה והפרדת מפתחות API**: כל משתמש מזין את המפתח האישי שלו, הנשמר ב-`localStorage` המקומי בלבד ולעולם אינו נחשף או משותף.

## פריסה ל-Render (Static Site)

1. צור מאגר (Repository) חדש ב-GitHub והעלה אליו את הפרויקט:
   ```bash
   git remote add origin https://github.com/USERNAME/advoice-studio.git
   git branch -M main
   git push -u origin main
   ```

2. היכנס לחשבונך ב-[Render.com](https://render.com) ולחץ על **New +** -> **Static Site**.
3. חבר את המאגר מ-GitHub.
4. הגדרות הפריסה:
   - **Build Command**: `npm install && npm run build`
   - **Publish Directory**: `dist`
5. לחץ על **Create Static Site** – תוך פחות מדקה האתר יהיה באוויר עם כתובת ציבורית מוצפנת ב-HTTPS ומוכן לשיתוף עם חברים!
